**BlastmasterServer** is the planned server counterpart or server edition of BlastmasterOS. The intention is to develop it as a distinct edition with server-oriented goals.

## Project relationship

- **BlastmasterOS** is the desktop-oriented operating-system project.
- **BlastmasterServer** is intended to be its server counterpart.

The two names describe related project directions, not interchangeable products.

## Development status

The server edition has been described as a future, separate repository/project. This Wiki therefore documents its intended relationship and does not claim that a finished server operating system, installer, administration console, or feature set is currently available.

## Future documentation topics

As the project takes shape, this article can grow to cover:

- Supported server roles and intended workloads.
- Installation and upgrade procedures.
- Network configuration.
- User, group, and permission administration.
- Storage and file-system management.
- Remote administration and security.
- Backup, recovery, and troubleshooting.
- Release support policy.

These are documentation topics to address when the corresponding functionality and decisions exist. They are not statements that those features are implemented.
