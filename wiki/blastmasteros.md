**BlastmasterOS** is an operating-system project exploring a classic desktop experience, theming, and system components. Its repository is the authoritative source for current code, build instructions, and project status.

[BlastmasterOS source repository](https://github.com/Blastmaster-Fixup-and-Kleanup-Crew/BlastmasterOS)

## Project goals

The project aims to develop a familiar desktop-oriented operating-system experience while evolving its own components and tooling. The exact state of individual features can change as development progresses.

## Development environment

The related **BosDE** project is intended to provide a development environment and toolchain for building BlastmasterOS components.

- [BosDE overview]({{ '/wiki/bosde' | relative_url }})
- [Windows build notes]({{ '/wiki/bosde-windows' | relative_url }})

## Installation and system requirements

Consult the BlastmasterOS repository for current installation media, supported hardware or virtual-machine configurations, and any release-specific requirements. Do not rely on an old screenshot or an outdated post as a compatibility guarantee.

## Feedback and bug reports

When reporting a problem, include as much reproducible information as possible:

1. BlastmasterOS version or commit, if known.
2. Whether the system is running on physical hardware or in a virtual machine.
3. Relevant hardware or virtual-machine configuration.
4. Steps that reproduce the problem.
5. Expected behavior and actual behavior.
6. Relevant logs and screenshots, especially for crashes, freezes, or visual defects.

Check the repository's current issue and contribution guidance before submitting a report.

## Related project

[BlastmasterServer]({{ '/wiki/blastmasterserver' | relative_url }}) is the planned server counterpart. It is a separate project direction, not a feature that should be assumed to exist in the current BlastmasterOS build.
