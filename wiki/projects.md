This page summarizes the projects currently highlighted on the BFKC website. It is an orientation guide, not a release or compatibility guarantee.

## Blastmaster Suite

A desktop productivity suite project with Docs, Presentations, Workbooks, and Databases.

Repository: [Blastmaster-Suite](https://github.com/Blastmaster-Fixup-and-Kleanup-Crew/Blastmaster-Suite)

## BlastmasterOS

An operating-system project exploring a classic desktop experience, theming, and system components.

Repository: [BlastmasterOS](https://github.com/Blastmaster-Fixup-and-Kleanup-Crew/BlastmasterOS)

Documentation: [BlastmasterOS Wiki article]({{ '/wiki/blastmasteros' | relative_url }})

## Docureader Exchange

A Qt-based document and PDF application project inspired by classic Acrobat Exchange workflows.

Repository: [Docureader-Exchange](https://github.com/Blastmaster-Fixup-and-Kleanup-Crew/Docureader-Exchange)

## Stratovise

A Windows-oriented virtual-machine application project using a Qt interface and a QEMU backend.

Repository: [Stratovise](https://github.com/Blastmaster-Fixup-and-Kleanup-Crew/Stratovise)

## Development infrastructure: BosDE

BosDE (BlastmasterOS Development Environment) is a related development-toolchain effort intended to support building operating-system components. It is documented separately because it is development infrastructure rather than an end-user application.

- [BosDE overview]({{ '/wiki/bosde' | relative_url }})
- [BosDE Windows build notes]({{ '/wiki/bosde-windows' | relative_url }})
- [BosDE repository](https://github.com/Blastmaster-Fixup-and-Kleanup-Crew/BlastmasterOS-Dev-Environment)

## BlastmasterServer

BlastmasterServer is the intended server counterpart to BlastmasterOS. It is a planned separate edition; it should not be treated as an already released server product.

Read [the BlastmasterServer article]({{ '/wiki/blastmasterserver' | relative_url }}).
