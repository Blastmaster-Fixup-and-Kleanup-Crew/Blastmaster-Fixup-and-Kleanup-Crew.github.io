| Term | Definition |
| --- | --- |
| **BFKC** | Blastmaster Fixup & Kleanup Crew. |
| **BosDE** | BlastmasterOS Development Environment, the toolchain/build-environment project. |
| **Compiler** | A program that translates source code into another form, commonly machine code or object code. |
| **Cross-compiler** | A compiler that runs on one host platform but generates code for a different target platform. |
| **GCC** | GNU Compiler Collection, including C and C++ compilers and supporting tools. |
| **G++** | The C++ compiler driver provided by GCC. |
| **GitHub Pages** | A service for publishing websites from a GitHub repository. |
| **Jekyll** | A static-site generator used by GitHub Pages to build pages from Markdown, layouts, and configuration. |
| **MinGW-w64** | Tooling and runtime components for building Windows applications with GCC-based toolchains. |
| **MSYS2** | A software distribution and environment providing Unix-like tools and native Windows toolchains. |
| **Native package** | A package formatted for and managed by a platform's package-management ecosystem. |
| **Target triplet** | A string identifying the target system/architecture/ABI used by a toolchain. |
| **Toolchain** | The compiler, assembler, linker, libraries, and related tools used to build software. |
| **Host** | The platform on which a build tool or compiler is running. |
| **Target** | The platform for which generated code or binaries are intended. |
