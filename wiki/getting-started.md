Welcome to the BFKC Wiki. This is the central documentation area for the projects and development work published by the Blastmaster Fixup & Kleanup Crew.

## Find your way around

- **[About BFKC]({{ '/wiki/about-bfkc' | relative_url }})** explains the organization and its working principles.
- **[Projects overview]({{ '/wiki/projects' | relative_url }})** links to the projects featured on the website.
- **[BlastmasterOS]({{ '/wiki/blastmasteros' | relative_url }})** covers the operating-system project.
- **[BosDE]({{ '/wiki/bosde' | relative_url }})** introduces the development toolchain project.
- **[Troubleshooting]({{ '/wiki/troubleshooting' | relative_url }})** provides a starting point when something goes wrong.
- **[Contributing]({{ '/wiki/contributing' | relative_url }})** explains how to suggest corrections and additions.

Use the search field in the sidebar to filter the article navigation. On the Wiki homepage, the search field filters the article directory.

## Understanding project status

| Status | Meaning |
| --- | --- |
| Active development | Work is currently being carried out; details may change. |
| Experimental | A feature or approach is being tested and may not be stable. |
| Planned | An intention or design direction, not a promise of delivery. |
| Available | The referenced code or documentation exists; check its repository for release details. |
| Archived | The project or component is no longer actively maintained. |

A description in this Wiki is not a substitute for a project's current README, release notes, source code, or issue tracker.

## Where to get authoritative information

Each project article links to its source repository. Repository documentation and the code itself take precedence if a Wiki article becomes outdated.

## Help improve the Wiki

If you find a broken link, unclear explanation, or outdated detail, use the correction link at the bottom of an article or follow the [contribution guide]({{ '/wiki/contributing' | relative_url }}).
