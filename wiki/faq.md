## Is BFKC one software product?

No. BFKC is the group behind several separate software projects. Each project has its own repository, scope, and development status.

## Where can I find source code?

Use the repository links on the [projects overview]({{ '/wiki/projects' | relative_url }}) or visit the [BFKC GitHub organization](https://github.com/Blastmaster-Fixup-and-Kleanup-Crew).

## Is BlastmasterServer available now?

BlastmasterServer is the planned server counterpart to BlastmasterOS. It has been described as a separate future project; do not assume a finished server edition or released feature set exists.

## What is BosDE?

BosDE means BlastmasterOS Development Environment. It is the toolchain and build-environment effort intended to support BlastmasterOS development.

## Does BosDE support every architecture and operating system today?

No such blanket support should be assumed. The project goal includes all intended architectures and Unix-like hosts including macOS, but platform support must be verified against completed build and test work in the repository.

## Can I contribute to the Wiki?

Yes. Read the [contribution guide]({{ '/wiki/contributing' | relative_url }}) for the recommended article structure and review process.

## Where should I report a bug?

Use the issue tracker of the repository responsible for the affected project. Include reproduction steps and relevant logs, and remove secrets before posting.

## Are Wiki articles guaranteed to be current?

No. Articles are maintained documentation, but active projects can change quickly. Check the source repository and its latest documentation when details matter.
