The **Blastmaster Fixup & Kleanup Crew (BFKC)** is an independent software project group. Its website presents projects spanning desktop productivity, operating-system experimentation, document tools, and virtualization.

## What we work on

BFKC explores software that is practical to use, approachable to learn, and documented clearly. Projects may have different goals, technologies, release schedules, and levels of maturity.

The public website currently highlights:

- **Blastmaster Suite** — a desktop productivity suite project.
- **BlastmasterOS** — an operating-system project exploring a classic desktop experience.
- **Docureader Exchange** — a Qt-based document and PDF application project.
- **Stratovise** — a Windows-oriented virtual-machine application project.

See the [projects overview]({{ '/wiki/projects' | relative_url }}) for repository links and descriptions.

## Working principles

### Usability
Interfaces and workflows should be understandable and practical.

### Compatibility
Projects consider existing workflows and file formats where their scope allows.

### Iterative development
Testing, issue reports, documentation, and review help guide improvements.

### Clear status
A planned feature should not be confused with a working feature or released product. This Wiki aims to label project status honestly.
