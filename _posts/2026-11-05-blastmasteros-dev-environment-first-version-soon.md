We are pleased to share that the **BlastmasterOS Dev Environment (BosDE)** is preparing for its first release.

BosDE is being developed as the dedicated development toolchain for **BlastmasterOS**. Its design is based on **RosBE**, and development on the environment has been underway for approximately two weeks.

## Supported platforms

For the planned first release, we intend to provide downloads for these supported host platforms:

- **PowerPC**
- **Unix**
- **Windows**

Release downloads will be made available when the first version is ready. Check this page and the source repository for release announcements and availability.

## Built for BlastmasterOS development

BosDE will serve as the development toolchain for BlastmasterOS, helping provide the tools needed to build and work on the operating system.

BlastmasterOS has been in its alpha stage for approximately three months and is currently at **Alpha Build 67**. The operating-system project is also based on the **ReactOS** project and is working toward compatibility with **Windows XP and Windows Server 2003**.

## Explore the source and contribute

BosDE is an open development project. Developers and interested contributors can inspect the source code, follow its progress, report issues, and contribute improvements through the GitHub repository:

**[BlastmasterOS Dev Environment — Source Code](https://github.com/Blastmaster-Fixup-and-Kleanup-Crew/BlastmasterOS-Dev-Environment)**

We welcome constructive contributions that help improve BosDE for everyone working on BlastmasterOS.

## First release coming soon

The first version is in development. More information, including platform-specific downloads, will be shared when release packages are ready.

Thank you for following the development of BlastmasterOS and the tools being built to support it.
